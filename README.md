# Lantern-Inhalte

Rohdateien der Startinhalte für Lantern (Bauplan Q-12, Entscheidung E-275 im Repo Projekt-Lantern/Lantern).
Hier liegen unveränderte Original-Dateien freier Packs, je Pack ein Ordner `<hersteller>/<pack>/` mit der
Lizenzdatei des Herstellers. Aufbereitung (glb, Maßstab, Kollision, Vorschaubilder) und das ZIP
`Lantern-Startinhalte-<Version>.zip` macht der Workflow im Haupt-Repo.

Erlaubt sind nur CC0 sowie MIT, Apache, BSD, zlib; Schriften OFL. Nie: Synty, Mixamo, KI-erzeugte Inhalte
ohne Entscheidung. Jedes Pack wird in `QUELLEN.md` mit Quelle, Commit und Lizenz eingetragen, bevor es
hierher kommt.
